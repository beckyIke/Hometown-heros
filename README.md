# Rim of the World Hometown Hero Banners

A read-only guide to the Hometown Hero banner poles in Crestline and Twin Peaks, CA: who is on each banner, photos of each pole, landmarks, condition notes, and a map pin for every location.

Live site: https://beckyike.github.io/Hometown-heros/

## Files

- `index.html` — the whole site (one page, no build step)
- `photos/` — photos of each pole, referenced by file name

To update, replace `index.html` (and add any new photos to `photos/`), then commit and push.
